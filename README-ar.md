# رفاهة وكشتة — نسخة جاهزة للرفع

## الحالة
تمت مراجعة الكود وتعديله بالقراءة فقط. لم تُجرَ اختبارات، ولم تُشغّل اللعبة، ولا توجد ملفات اختبار. التوافق الفعلي على iPhone والعمل دون اتصال غير متحقق منهما.
حُفظ الملفان الواردان دون تعديل في مجلد original خارج مجلد النشر. لم يتوفر الملف التاريخي المسمى «رفاهة وكشتة.html»؛ مصدر التعديل هو index.html داخل الحزمة التي أرسلتها.

## التغييرات
- منع إظهار الإجابة واحتسابها أثناء إيقاف الجولة، وإلغاء حالة الإيقاف عند بدء جولة جديدة.
- إبقاء النقر الأصلي للأزرار، دون جمع touchstart وclick بما قد يكرر الحركة.
- تحسين التمرير العمودي ومساحة اللوحة والأزرار ومراعاة حواف الشاشة ولوحة المفاتيح، مع بديل لوحدات ارتفاع الشاشة الحديثة.
- جعل ملء الشاشة وقفل الاتجاه اختياريين حسب دعم المتصفح.
- حماية قراءة سجل الأسئلة من بيانات محفوظة غير صالحة، وإظهار رسالة عند تعذر حفظ حساب محلي.
- إضافة زر يشرح التثبيت على الشاشة الرئيسية وأسماء وصفية لبعض أزرار الرموز.
- تقييد التخزين المؤقت بملفات اللعبة ونطاقها، وعدم حذف مخازن تطبيقات أخرى. ينتظر عامل الخدمة الجديد إغلاق النسخ المفتوحة قبل تفعيله.
- لم تُعدّل بيانات الأسئلة أو خوارزمية الاتصال والفوز أو عدد الجولات .

## سبب المشكلة السابقة
فتح HTML في معاينة تطبيق الملفات يختلف عن فتح موقع في Safari. لا يمكن الجزم بسبب العطل السابق دون فحص تلك البيئة؛ إذا كانت المعاينة لا تشغّل JavaScript فلن تعمل الأزرار. تحتوي النسخة رسالة لهذا الوضع. المسار المقصود هو رابط HTTPS منشور، لا معاينة ملف محلي.

## النشر على GitHub Pages
1. أنشئ مستودعًا في حسابك، مثل rafaha-game. النشر العام يجعل اللعبة وأسئلتها متاحة للزوار؛ اختر ذلك بعد موافقتك.
2. ارفع محتويات هذا المجلد مباشرة إلى جذر المستودع، بما فيها index.html والأيقونات وmanifest.webmanifest وsw.js وملف .nojekyll. لا ترفع مجلد original أو ملف ZIP الأصلي.
3. من Settings ثم Pages، اختر Deploy from a branch، والفرع main، والمجلد /(root)، ثم Save.
4. استخدم رابط الموقع الذي تعرضه صفحة Pages بعد اكتمال النشر. لحساب Mmalqf ومستودع rafaha-game يكون الرابط المتوقع https://mmalqf.github.io/rafaha-game/؛ لم يُنشأ هذا المستودع أو يُتحقق من وجود الرابط.
5. عند تحديث عامل الخدمة، أغلق جميع نسخ اللعبة المفتوحة ثم افتح الرابط مجددًا.

اتصال حساب GitHub متاح، لكن الأدوات المتاحة في هذه الجلسة لا تدعم إنشاء المستودع أو رفع الملفات أو تفعيل Pages. لم يتم نشر أو رفع شيء.

## الإضافة للشاشة الرئيسية على iPhone
افتح رابط الموقع المنشور في Safari ← المشاركة ← إضافة إلى الشاشة الرئيسية ← فعّل «فتح كتطبيق ويب» إن ظهر ← إضافة. يوجد داخل اللعبة زر بنفس الإرشادات.
يلزم اتصال أول مرة لتنزيل ملفات اللعبة، وقد تُحذف البيانات المحفوظة وفق إعدادات الجهاز. الخط العربي يأتي من Google Fonts وله بدائل محلية عند عدم توفر الشبكة. إضافة الأيقونة وحدها لا تثبت اكتمال التخزين دون اتصال.

## اللعب المباشر
تفتح النسخة إعداد اللعبة مباشرة، دون تسجيل دخول أو شراء أو تجارب محدودة. لا تقرأ مفاتيح الحساب والتفعيل والمحاولات السابقة. يستمر حفظ سجل الأسئلة محليًا فقط لتقليل التكرار.
لم تتغير الأسئلة أو قواعد الفوز. لم تُجر اختبارات لهذه النسخة.
