# رفاهة وكشتة

## تحديث بنك الأسئلة — ٢٠ أكتوبر ٢٠٢٦

النسخة تضم **2,982 سؤالًا** بصياغات جديدة في العلوم واللغة والأدب والتاريخ والفنون والجغرافيا والفلك والتقنية والاقتصاد وتاريخ الرياضة. لم يُستورد بنك الأسئلة الخام الذي روجع أثناء البحث. الأسئلة مؤلفة، مع مراجعة تحريرية ومصدرية انتقائية، وتصحيح الأخطاء والمرادفات التي ظهرت أثناء المراجعة. ليست جميع الحقائق موثقة فرديًا؛ التفاصيل والمراجع في [QUESTION-SOURCES.md](QUESTION-SOURCES.md).

- الصفحة الرئيسية محفوظة؛ اللعب مفتوح دون حساب أو شراء أو حدّ محاولات.
- يحتفظ المتصفح بمعرف السؤال فور اختياره، قبل عرضه. لا يعاد تدوير البنك عند نفاد الأسئلة.
- يستعمل الحفظ معاملة واحدة مشتركة بين نوافذ الموقع؛ تعذّر الحفظ يمنع عرض سؤال جديد مع إظهار السبب.
- يجري ترحيل سجل hu2 القديم باستخدام المطابقة وما أمكن ربطه بالإجابات السابقة. الترحيل محافظ وقد يستبعد أسئلة جديدة ذات إجابة سبق رؤيتها. لم يُمسح السجل القديم.
- تُخلط حروف الجولات من الأبجدية الكاملة وتُغيّر مواضعها مقارنة بالتوزيع السابق، الذي يُحفظ أيضًا بين الزيارات.
- يستبعد إنشاء الجولة الحروف التي نفدت أسئلتها. إذا لم تكفِ الحروف المتبقية للوحة ٥×٥، تقترح الرسالة اختيار ٤×٤ إن أمكن. عند نقصها عن ١٦ حرفًا يلزم توسيع البنك. لا نكرر حرفًا داخل اللوحة لإخفاء النفاد، ولا نغير قاعدة الاتصال والفوز.
- قد ينفد مخزون حرف قبل غيره؛ توزيع الإجابات بين الحروف غير متساوٍ. البنك محدود، ولا تتولد أسئلة جديدة من الإنترنت عند كل زيارة.

## استمرار السجل

السجل خاص **بنفس المتصفح ونفس عنوان الموقع**، وليس مزامنة بين الأجهزة أو Safari وChrome. مسح بيانات الموقع أو استعمال وضع خاص أو تغيير الدومين قد يبدأ سجلًا جديدًا. وقد يزيل المتصفح بيانات الموقع عند ضيق التخزين. لا توجد دعوى بحفظ أبدي خارج سيطرة المتصفح.

إذا ستنقل اللعبة إلى دومينك، استخدم الدومين النهائي للعب اليومي قبل البدء بتكوين سجل طويل. لا تمسح بيانات الموقع لحل مشكلة تحديث؛ أغلق جميع نوافذ اللعبة ونسختها المثبتة ثم افتح الرابط مجددًا متصلًا بالإنترنت.

## GitHub Desktop

المجلد المحلي المرتبط بالمستودع هو RAFA على سطح المكتب. راجع التغييرات في GitHub Desktop، ثم اكتب رسالة مثل «توسيع بنك الأسئلة ومنع تكرار المشاهد وخلط الحروف»، واضغط Commit to main ثم Push origin. لم ينشئ الوكيل كوميت أو يرفع تغييرات.

إذا كان GitHub Pages مضبوطًا على main والجذر، ينشر التحديث بعد الرفع. المسارات نسبية وتناسب GitHub Pages ودومينًا مخصصًا؛ لم نضف CNAME لأن الدومين لم يحدد.

## الإضافة للشاشة الرئيسية على iPhone

افتح رابط HTTPS المنشور في Safari ← المشاركة ← إضافة إلى الشاشة الرئيسية ← فعّل «فتح كتطبيق ويب» إن ظهر ← إضافة. يوجد زر بالإرشادات في الصفحة الرئيسية. يلزم اتصال أول مرة لتنزيل الملفات، والخط الخارجي له بدائل محلية عند غياب الإنترنت.
